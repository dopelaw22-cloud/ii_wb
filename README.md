# Менеджер WB

Помощник по маркетплейсу Wildberries. Работает на сервере под пользователем `wb`,
полностью изолирован от проекта Ozon: отдельный системный пользователь, отдельная
база данных, отдельная tmux-сессия, отдельный Telegram-бот.

## Где что лежит

| | |
|---|---|
| Проект | `/home/wb/Менеджер WB/` |
| База данных | `wb_ops`, схема `ops` |
| Журнал операций | `/home/wb/oplog/db_log.py` |
| tmux-сессия | `wb` (поднимается `tmux-wb.service`, переживает перезагрузку) |
| Секреты | `.env` в корне проекта и `/home/wb/oplog/.env` — оба 600, вне git |

## Вход

```
ssh wb@153.80.242.63        # по ключу, без пароля
wb                          # от root: сразу в рабочую tmux-сессию
```

## Агент-аналитик

Считает прибыль по каждому товару, разбирает рекламу, карточки и воронку,
присылает отчёты и рекомендации в Telegram. Подробности — в `AGENTS.md`.

Бот: **@wb_permin_bot**. Напишите ему `/start` — и дальше `/прибыль`, `/реклама`,
`/советы`, `/отчет`. Свободный вопрос текстом тоже работает: бот поднимает
headless-сессию Claude с правами только на чтение и отвечает в чат.

```
systemctl --user status wb-analyst-bot     # нужен XDG_RUNTIME_DIR=/run/user/1001
cd "1. analyst/2. script" && python sync.py    # собрать данные вручную
```

### Главное ограничение
Лимиты WB API измеряются **часами**: финотчёт — раз в ~8 ч, продажи — раз в
~1,7 ч, воронка — раз в ~24 мин, и попытка расходуется даже при неудаче.
Поэтому все данные кешируются в БД (схема `wb`), отчёты собираются из кеша,
а каждый вызов идёт через `wb_lib.call()`, который помнит окна в
`1. analyst/3. work/api_state.json`. Команда `/лимиты` в боте показывает,
что когда снова станет доступно.

## Автоматические задачи

| Когда | Что |
|---|---|
| Ежедневно 05:30 | сбор данных WB и пересчёт экономики (`sync.py`) |
| Ежедневно 08:30 | отчёт в Telegram владельцу (`report.py --telegram`) |
| Ежедневно 13:30 | добрать то, что утром было под лимитом |
| Понедельник 09:15 | push кода в GitHub (`auto_push_ii_wb.sh`) |
| Воскресенье 04:10 | дамп `wb_ops` в Telegram-бот `@backup_basa_wb_bot` |

Все запуски логируются в `ops.agent_run`. Логи: `~/auto_push.log`,
`~/oplog/backup.log`, `1. analyst/3. work/{sync,report,bot,catchup}.log`.
На диске хранятся 4 последних дампа, дальше — ротация.

## Доступ к WB API

Токен `WB_API_TOKEN` в `.env`, боевой, действует до 2027-04-01.
Проверка всех разделов одной командой:

```
/home/wb/oplog/venv/bin/python "0. orchestrator/2. script/wb_api_check.py"
```
